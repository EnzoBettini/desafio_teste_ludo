# desafio_teste_ludo

## Especificação do desafio

Partida de **Ludo para 2 jogadores**.

A implementação deve suportar (conforme regras documentadas nos testes):

- Tabuleiro, peças, dados e alternância de turnos
- Saída da base, movimento, capturas e área final
- Condição de vitória

Código em `src/`; casos de teste em `tests/` (JavaScript + Jest).

## Como executar os testes

```bash
npm install
npm test
```

Modo observação:

```bash
npm run test:watch
```
